# Validated example: PR 14872 (2026-09-07)

Two isolated A3 containers compiled vLLM-Ascend PR HEAD
`dc08ab8602b740e4461812e4ee58bc0ebd9a21ef` with vLLM
`e6bfe03ad73a3330cb427885aa90d97a12e1c704`.
PR base: `e27ffbb71046a381e5e899df061d9c8a681f4a18`.
The hardware-compatible image used was
`quay.io/ascend/vllm-ascend:nightly-main-a3`.

Although the PR itself had no csrc changes relative to its base, the image
plugin source (`14784edc…`) to PR base comparison included 104 changed csrc
files. Python replacement alone would therefore have mixed new Python with
older native operators. Both containers received a complete plugin build.
The target catlass submodule was `41bf90da…`; resolve the full gitlink from
the target revision when reproducing, rather than using this abbreviated SHA.

Successful jobs `pr14872-build-p4` and `pr14872-build-d4` ran
`python -m pip install -e . --no-deps --no-build-isolation` in the isolated
plugin source directory. Their explicit build environment included
`MAX_JOBS`, `CMAKE_BUILD_PARALLEL_LEVEL`, and `SOC_VERSION`. This example does
not prescribe their values for other hardware. Source hashes on P and D
matched the PR worktree for the V1 runner and Mooncake hybrid connector.

Runtime validation used DSV4 Flash w8a8 MTP, Model Runner V1,
P DP2×TP4 and D DP8×TP1, eager execution and prefix caching disabled.
All 1319 AISBench GSM8K requests completed successfully; accuracy was
1188/1319 (90.0682%). The 1024-token output cap was reached by 142 outputs,
including 113 of the incorrect answers, so this was not a clean no-regression
accuracy comparison. Services remained running after evaluation.

A separate graph-mode launch did not become ready after capture and logged
`No available shared memory broadcast block found in 60 seconds`; a missing
`causal_conv1d_update_npu` fallback warning was also observed. This run proves
eager operation only and does not establish that either warning caused the
graph stall. Build success does not eliminate independent source-level PD
memory-layout defects found during review.

The experiment used `VLLM_VERSION=0.27.1.dev0` for main-version semantics.
Do not copy this override to another revision: first inspect its version
gates and record any override separately from source parity. Changing a
version string does not create ABI or code compatibility.
